## 2025-02-18 - Keyboard Navigation & Short-cut Context Awareness
**Learning:** Custom UI components like carousels/sliders are often completely inaccessible to screen readers and keyboard-only users. Merely adding swipe or wheel tracking is insufficient. Adding `tabIndex={0}`, `role="region"`, `aria-roledescription="carousel"`, along with exact keyboard handlers (`ArrowLeft`, `ArrowRight`), restores complete structural parity. Furthermore, global shortcuts like Spacebar can interfere with form fields unless they are strictly gated against standard tags like `INPUT`, `TEXTAREA`, and `BUTTON`.
**Action:** When creating any global keyboard listeners or custom gesture-based carousels, always verify structural and interactive screen-reader parity using appropriate roles and focus-ring highlights, and gate keyboard shortcuts using target element tag names.
