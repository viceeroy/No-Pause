## 2025-05-15 - Global Keyboard Shortcuts for Primary Actions
**Learning:** In recording-focused applications, users often prefer hands-free or keyboard-driven control for starting and stopping. Using the 'Space' key is a standard and expected pattern that significantly improves accessibility and speed.
**Action:** Implement 'Space' bar listeners for primary session actions (start/stop) and provide subtle visual hints ([Space]) to aid discovery on desktop, ensuring they are gated from standard input elements.
