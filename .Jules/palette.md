## 2025-05-15 - Keyboard Accessibility and Discoverability
**Learning:** Users on desktop expect standard keyboard shortcuts (Space to start/stop, Arrows for navigation) and discoverability hints like `[Space]` aid adoption of these power-user features. Proper ARIA roles and focus states are essential for accessible carousel components.
**Action:** Always include global keyboard listeners for primary actions, add visual shortcut hints for desktop users, and ensure interactive custom components have appropriate ARIA attributes and visible focus rings.
