## 2026-06-15 - Global Spacebar and Keyboard Accessible Prompt Carousel
**Learning:** Implementing keyboard navigation (`ArrowLeft` / `ArrowRight`) on custom carousels using `tabIndex={0}`, `role="region"`, and screen-reader `aria-hidden` states significantly boosts accessibility. Adding global keyboard shortcuts like `Space` for primary media control (start/finish) is a tremendous micro-UX delight, but they must be gated to ignore input elements (`INPUT`, `TEXTAREA`, `BUTTON`) and paired with responsive `[Space]` visual helpers that only show on desktop devices.
**Action:** Always focus-wrap keyboard listeners, prevent default behavior when keys are handled, design subtle discoverable hints, and verify screen-reader compliance with `aria-live` and `aria-atomic` for countdown alerts.
