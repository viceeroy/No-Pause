## 2025-05-14 - Keyboard-accessible carousels and global shortcuts
**Learning:** For keyboard-accessible carousels or selection regions, use 'role="region"', 'aria-roledescription="carousel"', 'tabIndex={0}', a descriptive 'aria-label', and provide visual 'focus-visible' states. Standardized 'focus-visible' pattern for the application's design system: 'focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 outline-none'. When implementing global keyboard shortcuts (e.g., Space), gate the listener using '!['INPUT', 'TEXTAREA', 'BUTTON'].includes((e.target as HTMLElement).tagName)' to prevent unintended triggers while the user interacts with standard form elements or buttons.
**Action:** Apply these roles, attributes, and gating patterns to any future interactive selection components or global shortcuts.
