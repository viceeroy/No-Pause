
## 2024-05-20 - [Accessibility: Keyboard Navigation for Carousels]
**Learning:** For touch/swipe-based carousels, providing keyboard navigation (Arrow keys) and proper ARIA roles (region, group, slide) is essential for accessibility and improves the desktop experience.
**Action:** Always include tabIndex={0}, onKeyDown, and ARIA roles when implementing or enhancing carousel-like components.
