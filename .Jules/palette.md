## 2025-02-15 - Enhancing Prompt Carousel Keyboard Accessibility & Screen Reader Visibility
**Learning:** In highly visual, swipe-based custom React carousels (such as the prompt selection region in `SetupCountdownPanel`), keyboard navigation is often completely neglected because touch and pointer events dominate the implementation. Furthermore, keeping all slides rendered in the DOM without hiding inactive ones causes screen readers to announce a massive wall of text containing every single prompt option at once, overwhelming assistive technology users.
**Action:** Always assign `tabIndex={0}`, `role="region"`, `aria-roledescription="carousel"`, and a descriptive `aria-label` to custom carousel wrappers, and listen to `ArrowLeft` and `ArrowRight` keyboard events to enable focus-visible navigation. Additionally, apply `aria-hidden={i !== activeIndex}` on each slide card to ensure screen readers only perceive the single, actively displayed slide.
