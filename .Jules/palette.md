# Palette's UX Journal

## 2026-08-08 - Contextual Stats inside Integration Launchers
**Learning:** Displaying integration-specific stats (like Telegram challenge counts and wins) directly inside the entry-point launcher card, rather than in a disconnected panel, provides high-context value at the exact point of feature discovery. For screen reader users, keeping this info within the main focused anchor allows seamless status announcement.
**Action:** Always identify if a third-party integration or feature launcher can double as an inline status summary to keep the UI clean, highly-cohesive, and naturally discoverable.
