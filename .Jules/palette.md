## 2025-07-17 - Keyboard-Accessible Carousels and Space Shortcuts
**Learning:** Keyboard accessibility for horizontal interactive regions (like custom carousels) requires clear landmark roles (role="region", aria-roledescription="carousel"), explicit focusability (tabIndex={0}), explicit focus states matching the design tokens, and horizontal arrow key listeners. When implementing global space key listeners, it is crucial to gate target element tags (!['INPUT', 'TEXTAREA', 'BUTTON'].includes(target.tagName)) to prevent double triggers on standard controls, and to supply visual shortcut indicators matching the visual system.
**Action:** Always combine tabIndex={0} with explicit focus-visible borders/rings and arrow-key event handlers for custom horizontal selectors, and ensure global space key listeners prevent default actions only when not focused on standard interactive controls.
