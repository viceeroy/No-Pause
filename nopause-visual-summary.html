NoPause — speak more, pause less.

A privacy-first speech fluency PWA that listens to you in the browser, measures hesitation pauses, and gives you a single number — the Flow Score — to track progress over time. The same scoring engine also runs as a Telegram bot for voice-note practice on the go.

React + Vite + TS / Supabase + Groq / Vercel serverless / Telegram (Telegraf) / PWA

01How a Session Flows

Each practice session runs the same four-stage pipeline — whether you record in the browser or send a Telegram voice note. The only difference is which client triggers it.

step · 01

Capture audio

Microphone streams into the browser via Web Audio API. Live analysis happens locally — nothing is uploaded mid-session.

step · 02

Transcribe

Audio blob is sent to /api/transcription → Groq Whisper, returning the transcript plus word-level timestamps.

step · 03

Score

Gap analysis on word timestamps feeds the Flow Score formula. The shared silence helper runs identically on web and Telegram.

step · 04

Coach (optional)

When a topic was set, Groq LLM grades the response on a 1–9 band and returns AI feedback. Otherwise the result is shown without coaching.

02The Flow Score Formula

A single frozen formula in src/lib/core/scoring.ts. The same source of truth runs on web and Telegram — never forked, never approximated. Three inputs, one output.

// src/lib/core/scoring.ts · calculateFlowScore
speakingTime = floor(speakingTimeSec)
// sub-5s speaking = no score (session not completed)
completedMinutes = floor(speakingTime / 60)
score = max(0, speakingTime + completedMinutes × 40 − totalSilenceSec)

Worked example

speakingTime 90 sec
completedMinutes 1 (90 ÷ 60)
totalSilence 30 sec
score 90 + 1·40 − 30 = 100

1.5s Silence threshold — gaps between words ≥ 1.5s count as silence; shorter gaps are normal speech rhythm. Fixed in src/lib/core/constants.ts. Not a user setting.
≥ 5s Speaking floor — sessions shorter than 5 seconds return score = 0 with isCompleted = false. The session is still saved, but does not count toward streaks.
band · 10 AI bonus (Telegram only) — when a challenge has a topic, Groq returns a 1–9 band. applyBandBonus(baseScore, band) adds band × 10 on top of the base score.

03Two Front Doors, One Pipeline

Users can practice in the PWA or in Telegram. Both clients hit the same shared scoring and silence helpers — no fork.

Web PWA

In-browser practice

  • Live Web Audio analysis during recording
  • Real-time silence detection (RMS pipeline, disabled for scoring)
  • 3s countdown before recording starts
  • Optional prompts from /prompts
Telegram bot

Voice notes on the go

  • Bot: @NoPauseAI_bot via Telegraf webhook
  • Account linking via /connect?tg=<id>
  • 5-minute voice cap, shared Flow Score
  • Friend / group challenges with leaderboard

05Privacy by Construction

Live analysis stays in the browser tab. Raw audio is never streamed to servers during a session — it only leaves the device when the user explicitly stops recording, and only to produce a transcript.

AudioContext, not MediaStream uploads

Web Audio's AudioContext + AnalyserNode handle silence detection locally. Backend features (transcription, AI feedback, Telegram voice) process audio only when explicitly triggered, with per-user daily quotas via a Supabase RPC.
