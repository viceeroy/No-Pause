# No Pause Product Design Figma Plugin

This plugin creates an editable Figma board for the current No Pause web product.

It is intentionally Free Speaking-focused:
- Dashboard / Home
- Practice Recording
- Results
- Stats
- Auth
- Empty, loading, and error states
- Design system and mobile / desktop layout examples

It does not create Lemon, Topic, or Reading Challenge as active web modes.

## Use

1. Open Figma desktop.
2. Go to `Plugins > Development > Import plugin from manifest...`.
3. Select `manifest.json` in this folder.
4. Run `No Pause Product Design`.

The plugin will create a new Figma page named `No Pause - Product Design`.
